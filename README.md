# Model Internals Safety

Research on safety **inside model parameters**: how safety behavior is carried in the weights and activations of open language models, and how training-time and activation-level interventions can strengthen it.

This line complements [llm_guardrail_security_public](https://github.com/vacantfury/llm_guardrail_security_public), which studies safety from outside a frozen model.

## Papers and code

Papers from this line are listed here once they have a public preprint or a published version. The code is released together with them.
